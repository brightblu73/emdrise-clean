# 🚀 EMDRise Mobile App - Developer Quick Start

## ✅ **YOU'RE IN THE RIGHT PLACE**

This `mobile-app/` directory contains the **production-ready EMDRise mobile application**.

## 🔧 **Setup (2 minutes)**

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm start
```

### 3. Run on Device/Simulator
```bash
# iOS
npm run ios

# Android  
npm run android
```
